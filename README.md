# Codex App Mint Port

Temporary, local Linux Mint Cinnamon porting flow for the macOS-only Codex App.

This repository does not redistribute the app itself. It rebuilds a local runtime from the official OpenAI `Codex.dmg`.

## Provenance

This repository was generated by Codex, OpenAI's coding agent powered by GPT-5, and then cleaned up for publication after validating the build flow on Linux Mint Cinnamon.

## What it does

`./port-codex-app-mint.sh`:

1. checks local dependencies
2. downloads a Codex `.dmg` or appcast `.zip` archive from the official OpenAI CDN, unless you provide your own archive
3. extracts the macOS app bundle and `app.asar`
4. rebuilds `better-sqlite3` and `node-pty` for Linux/Electron in an isolated temporary project
5. applies the Linux-specific patches required for the app window and native module loading
6. downloads a local Electron runtime
7. creates a launcher under `./runtime/codex-app/start.sh`
8. installs or refreshes a user-level desktop entry in `~/.local/share/applications/codex-desktop.desktop`

## Design constraints

- no updater service
- no `pkexec`
- no system-wide installation of the app itself
- no `sudo npm install -g ...`
- local runtime only, under `./runtime/`
- user-level `.desktop` integration only

## Requirements

On Linux Mint / Ubuntu:

```bash
sudo apt install curl unzip p7zip-full python3 build-essential
```

You also need:

- Node.js 20+
- `npm`
- `npx`
- an installed Codex CLI available in `PATH`, or reachable through `CODEX_CLI_PATH`

## Usage

Build using the upstream DMG URL:

```bash
cd <project-dir>
bash ./port-codex-app-mint.sh
```

Build from an already downloaded DMG:

```bash
cd <project-dir>
bash ./port-codex-app-mint.sh --dmg /path/to/Codex.dmg
```

Build from an official appcast archive URL:

```bash
CODEX_PORT_SOURCE_URL='https://persistent.oaistatic.com/.../ChatGPT-darwin-arm64-<version>.zip' \
  bash ./port-codex-app-mint.sh --skip-desktop-entry
```

Use only an official appcast enclosure URL for archive sources. `--archive PATH`
accepts an already downloaded `.dmg` or `.zip`; `--dmg PATH` remains a
compatibility alias. `CODEX_PORT_SOURCE_URL` overrides the source URL, while
`CODEX_DMG_URL` remains supported as its DMG compatibility alias.

Force a clean rebuild:

```bash
cd <project-dir>
bash ./port-codex-app-mint.sh --fresh
```

Update an existing port safely:

```bash
cd <project-dir>
bash ./update-codex-app-mint.sh
```

The updater reads the official release feed, builds into a staging directory,
verifies the staged version, and keeps the previous runtime as a rollback copy.
Codex Desktop must be closed before the final replacement.

Skip desktop entry refresh:

```bash
cd <project-dir>
bash ./port-codex-app-mint.sh --skip-desktop-entry
```

## Generated output

The generated launcher is:

```bash
<project-dir>/runtime/codex-app/start.sh
```

The generated desktop entry is:

```bash
~/.local/share/applications/codex-desktop.desktop
```

## Assumptions

- the upstream `Codex.dmg` remains available at the current OpenAI CDN URL
- Electron `40.0.0` remains compatible with the current upstream app bundle
- the upstream bundle still contains `better-sqlite3` and `node-pty` in a form that can be rebuilt on Linux

If OpenAI changes the bundle structure, the patch step may need to be updated.

## Experimental Browser and Computer Use

The Linux port includes a compatibility implementation for Codex Browser and an
X11 desktop-control MVP. Browser support is configured automatically.

Desktop control is disabled by default. Start Codex with:

```bash
CODEX_LINUX_COMPUTER_USE=1 ./runtime/codex-app/start.sh
```

Desktop control currently targets Linux Mint Cinnamon on X11. It requires an
active `DISPLAY`, `wmctrl`, `xrandr`, `gnome-screenshot`, Python 3, and the X11
and XTest shared libraries. Wayland is rejected with a clear error.

Run the compatibility smoke tests after building:

```bash
node tests/linux-automation-smoke.mjs
```
